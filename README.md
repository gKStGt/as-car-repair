# AS Car Repair Website (Entwurf)

Statische Startseite für AS Car Repair, Otto-Hahn-Straße 2, 71254 Ditzingen-Heimerdingen.

- `index.html`: komplette Seite, kein Build, keine externen Dienste (keine Google Fonts, kein Google Maps)
- `assets/logo-symbol.png`: freigestelltes Logo-Symbol (der Schriftzug ist Live-Text)
- Dunkel-/Hellmodus mit Schalter, Auswahl wird im Browser gespeichert

## Stand

Entwurf. Die Seite enthält `<meta name="robots" content="noindex">`, damit Platzhalter nicht in Google landen. Vor dem Livegang entfernen.

Offene Platzhalter (in eckigen Klammern im Text):
- Vorher/Nachher-Fotos
- Foto Ahmet Celik, Qualifikation, Gründungsjahr
- Google-Bewertungen

Offene Punkte:
- Kontaktformular sendet nichts (nur Optik), braucht ein Backend oder einen Formular-Dienst
- Impressum und Datenschutz fehlen (Footer-Links zeigen nur auf die Fußzeile)
- Mechatronik steht nicht in den Leistungen (nicht auf der Visitenkarte)
